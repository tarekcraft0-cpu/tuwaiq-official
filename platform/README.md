# Crow — بطولات قروب كرو

منصة إدارة بطولات قروب كرو (Plato).

## التشغيل المحلي

```bash
npm install
npm run dev
```

## حساب المشرف الافتراضي

- اليوزر: `CrowAdmin`
- الباسورد: `crow123`

## النشر المجاني (رابط ثابت)

الأفضل: **Vercel** (مجاني ولا يطفى مثل بعض الاستضافات).

```bash
npx vercel --prod
```

## قاعدة بيانات مشتركة (لاحقاً)

حالياً البيانات محلية في المتصفح.  
عشان كل القروب يشوف نفس البطولات: Supabase (مجاني) — راجع `DATABASE.md`.
